# Verified owner ring

Original frames copied without changes from the user-supplied directory:
`nsoz/NsoServer/Data/Img/Small/4/Small1856.png` through `Small1859.png`, in that order.

The ring decorates the existing shield/check and does not determine verification. The badge is rendered only when the API returns `isOwnerVerified: true`. Animation runs twice, then returns to its static first frame. Reduced-motion users get a static frame, and forced-colors mode hides the decoration while retaining the label and check.
